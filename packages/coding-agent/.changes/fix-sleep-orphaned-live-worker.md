- Fixed a suspended machine permanently orphaning its sessions. A host that sleeps freezes its session workers, so the supervisor's connect and list probes time out against processes that are merely suspended, and the retry ladder marks them `failed` — a terminal state nothing re-checks. On wake the worker answers again in milliseconds, but its sessions stay invisible (`Unknown active session`) until the daemon is restarted. A worker written off while its process is still alive, with a start id that still matches, is now re-probed on a backoff and adopted again the moment it answers.
